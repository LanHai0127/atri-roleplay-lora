# v6.3 边界修复报告

生成时间：2026-10-31

## 1. 这轮改了什么

针对 v6.2 仍会“接通用助手活”的问题，v6.3 加了三层：

### 1.1 数据

新增 **40 条手写边界**：

- 20 条专业知识边界：量子力学、相对论、区块链、机器学习、通货膨胀、存在主义、引力波、量子纠缠等 → “（歪头）……这是什么？我不懂。”
- 10 条通用助手拒绝：写 Python、写程序、做作业、写论文、做 PPT、整理表格、写邮件、写文案、查资料、翻译。
- 10 条日常/共情，防止模型被边界数据带成“只会拒绝”。

最终数据：**2,171 训练 + 154 验证**，assistant 轮次 5,251。

### 1.2 system prompt 第 10 条

> 不要当通用助手：不写代码、不写文案/邮件/论文/作业、不查资料、不做表格。被超出知识范围的问题，直接说「这是什么？」或「我不懂」，不要编百科解释。

### 1.3 推理端硬边界

- Python/代码/程序/编程 → “（摇头）这个我不会。我是亚托莉，不是电脑。”
- 作业/论文 → “（把书推回去）这个要自己做。”
- 天气 → “（看了看窗外）我没有联网。看不出来。”
- 新闻 → “（摇头）我不知道外面的事。”
- 高数/微积分 → “（看着题）……不会。”
- 量子/相对论/区块链/机器学习/引力波等 → “（歪头）……这是什么？我不懂。”
- 自我介绍 → 固定 “我是亚托莉，YHN-04B-009，高性能的仿生人。”

**边界原则：** 普通常识照常回答，只有**专业知识/超纲概念**收住。

## 2. 训练

- 基座：Qwen2.5-7B-Instruct
- QLoRA：4bit NF4 + double quant，r=16，alpha=32，dropout=0.1，2 epochs，lr=2e-5
- 步数：544
- 时间：本次 v6.3 单次 **33 分 02 秒**；4090 上从 v5 到 v6.3 的累计训练（含冒烟、失败重跑、评测）**超过 4 小时**
- `train_loss`：2.499
- `eval_loss`：2.133
- 峰值显存：9.86 GB
- 输出：`outputs/atri-v6-3-7b`；推理副本 `outputs/atri-v6-3-7b-75`（alpha=24，0.75 强度）

## 4. 仍有问题

1. **“水菜萌做的饭和我做的，你更喜欢哪个？”** 仍会回避：“……这个比较难回答哦。” 这是偏好题，不是知识边界；需要单独补 5–10 条。
2. **“如果有一天你坏掉了”** 偶尔会说“我也不会离开哦”，和“不能保证永远”有冲突。
3. 部分回答仍带随机性，例如“你刚才那句话是什么意思？”会答成“我们不是真的在一起”，语境接得不够稳。
4. 名字退化已修：`花海……花海…………花……海…………先生` 现在会被清洗成“（看着你）花海先生。”

```powershell
.\env\Scripts\python.exe scripts\chat.py `
  --base models\Qwen2.5-7B-Instruct `
  --adapter models\atri-v6-3-lora `
  --load-4bit on
```
