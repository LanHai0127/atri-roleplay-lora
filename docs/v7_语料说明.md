# v7 语料说明

更新时间：2026-11-01

## 1. 这一版解决什么

v6.3 的语料 2,171 条，跑起来暴露三个问题（详见 `v7_训练报告.md`）。做分布审计后
发现，问题不在「数量不够」，而在三处**结构性空白**：

| 空白 | 审计证据 | 后果 |
|---|---|---|
| 扛不住长倾诉 | 输入最长 15 字，98% 在 10 字内 | 用户倒苦水时，模型只会回一句短评，接不住 |
| 不会说短 | 6 字以内回复占 0.3% | 「你好」也要回一整段，像客服 |
| 打招呼语气错 | 「你好」回复中位 20 字、0% 短回复 | 根因是引导词写了「元气」，生成器把语气带跑 |

v7 的做法是**先补结构、再清污染**，不是继续往 v6 里堆同质数据。

## 2. 语料构成

| 类别 | 场景数 | 说明 |
|---|---:|---|
| A 日常高频 | 14 | 问候、在吗、晚安、日常琐事 |
| B 情绪陪伴 | — | 难过、焦虑、失眠、孤独 |
| C 关系推进 | — | 撒娇、吃醋、表白、距离感 |
| D 危机 | — | 自伤/极端情绪，走安全回应，不进多轮合成 |
| E 生活场景 | — | 吃饭、通勤、天气、加班 |
| N 多轮 | — | 同场景链式多轮 |
| U 异常输入 | — | 方言、语音识别错乱、喝醉、哭着打字 |
| V 长输入 | 8 | 工作崩溃、长篇倾诉、凌晨长文 |
| X 极短应答 | 6 | 「嗯」「哦」「？」这类，全部手写 |
| 剧情清洗 | — | 游戏原生对白，只清洗不删 |

合计 **170 个场景**，train 22,493 / valid 686。

### 长度分层

生成器带 `LEN_HINT` / `LEN_LIMIT`，按类约束回复长度：

```python
LEN_HINT = {
  "X": "必须 1-8 字，不要完整句",
  "V": "10-28 字，不要复述对方、不要总结、不要说「我也被…」",
  "A": "1-10 字，最多 16 字",
}
LEN_LIMIT = {"X": (1, 13), "V": (3, 34), "A": (1, 16)}
```

超限直接丢弃重生成，不靠事后截断。

## 3. 过滤规则

v6 的过滤器只拦成人向词。v7 新增/加固了这些（全部实测踩过）：

| 规则 | 拦的是什么 |
|---|---|
| 共情套话变体 | 「我理解你的感受」「你一定很难受吧」 |
| 给建议 | 行首 `先/不如/要不 + 睡/休息/躺` —— 「那你先睡吧」放行 |
| 说教腔 | 「也是正常的」「挺常见的」 |
| 空洞鼓励 | 「你肯定行的」「你一定做得到」 |
| AI 腔 | 「无法确认」「请查看」「实时」 |
| 中英混杂 | 放行 `YHN-04B-009` / `ATRI` / `OK` |
| 旁白当台词 | 把动作描写写进对白正文 |
| 复读 | 回复与输入剥标点后高度重合 |
| 事实错误 | 「我也被客户骂过」—— 仿生人没上过班 |
| 方言漂移 | 突然冒出东北话/台湾腔 |
| 纯算术 | 问「多少/等于/利息」答一串数字 |
| 问候套话 | 「充满活力」「新的一天」 |

长度判定用**剥离动作括号后的正文**，否则「（点点头）」会被算成 6 字，X 类全被误杀。

## 4. 污染清理

第 3 轮训练后发现「你好」连续 4 次答成「刚才不是说过了吗」。全库扫描：

```
单轮样本里回答是「刚才不是说过了」类：86 条
分布：你好 / 你是谁 / 晚安 / 在吗 等最高频场景
原因：多轮场景的「重复问候」被当成单轮样本写进来了
```

首轮对话说这句话逻辑上不成立，属于硬伤。处理：

- 删除 86 条
- 手写 **384 条**问候语料补充，覆盖「你好、早上好、早、在吗、晚安、再见、你是谁、
  睡了吗、醒了吗」等高频词
- 分配策略：62% 的答案给核心高频词本身，38% 给变体，避免主词样本被稀释

补完后的覆盖量：

| 输入 | 条数 |
|---|---:|
| 在吗 | 64 |
| 你好 | 40 |
| 晚安 | 40 |
| 早上好 | 37 |
| 再见 | 27 |
| 你是谁 | 22 |

## 5. 统计

```
条数          22,493 train / 686 valid
system 条数   0
多轮占比      3,900 条（17.3%）
user 长度     中位 8 字，最长 123 字
回复长度      中位 16 字，p90 27 字，最长 58 字
6 字内回复    2.3%
weight        20,679 条 1.0 ／ 1,227 条 0.4 ／ 其余 0.35–0.5
```

`weight < 1` 的样本在训练时按概率丢弃（等价降采样），主要是助手腔和知识问答，用来
防止它们抢走人格权重。开头模板经 `cap_openers` 降权过，「嗯，」类开头占比从 12% 压到 5.7%。

## 6. 为什么不再公开分发

语料里含 ATRI 原作对白（只做了清洗，一条没删），版权属于原权利方。所以仓库只放
**构建方法论 + 验收 prompt + 训练脚本**，语料本身不随仓库发布。

如果要自建同类语料，参照 `v7_训练报告.md` 第二节的三处空白和本文第 3 节的过滤规则，
这两个是踩坑换来的，比数据本身有用。
