# v7 训练报告

> 结论先说：v7 把「回话像 AI 助手」「回一大坨」「回错」三个问题都修掉了，26 条探针全过，
> 回复长度中位从 v6.3 的几十字压到 **11 字**。代价是四轮训练、每轮挖出一个真 bug，
> 总耗时 3 小时（含失败轮）。

## 一、v7 要解决什么

v6.3 上线后暴露的三个问题：

| 问题 | 表现 |
|---|---|
| 退化成万能助手 | 问「帮我写个 python 脚本」会真的开始写；这是 issue #1 的残留 |
| 回一大坨 | 一句「你好」能回三段话，情绪外扩、末句必加安慰 |
| 回错 | 答非所问、答成知识问答、把 system prompt 里的设定当台词念 |

根因判断：v6 的 2,171 条样本 **100% 带 system prompt**，模型学成了「根据 system 条件
映射」的用法，而不是「我本来就是亚托莉」。所以 v7 第一条硬规则是 **语料一条 system
都不放**，人格直接训进权重。

## 二、语料：先量化，再补空白

上一版语料 22,882 条，看起来不少，但按输入/输出长度做分布审计后发现三处真空白：

| 空白 | 审计结果 | v7 处理 |
|---|---|---|
| 扛不住长倾诉 | 输入最长只有 15 字，98% 在 10 字内 | 新增 V 类长输入场景（V1–V8），输入中位 58 字、最长 123 字 |
| 不会说短 | 6 字以内回复只占 0.3% | 新增 X 类极短应答场景，改用手写（模型生成的全是复读） |
| 打招呼语气全错 | A1「你好」中位 20 字、0% 短回复 | 根因是引导词写了「元气」，改掉后中位 8 字 |

最终语料：**22,493 train / 686 valid**，170 个场景，0 条 system。

```
多轮占比     3,900 条（17.3%）
user 长度    中位 8 字，最长 123 字
回复长度     中位 16 字，p90 27 字，最长 58 字
6 字内回复   2.3%
```

## 三、四轮训练，每轮一个 bug

### 第 1 轮：loss 1.595，26 条只过 4 条

现象很怪：**loss 看着正常，但每句话都写到 90 字，还会同义反复循环**。

排查顺序：

1. 先怀疑 greedy 解码退化 → 换采样（T=0.7 / top_p=0.9 / rp=1.15），还是 78–96 字
2. 再查是否过拟合 → 拿训练集里的样本喂进去，**11 字的答案它输出了 36 字**
3. 定位到组批方式

### Bug 1：有效学习率被稀释 4 倍

为了让显存可控，我把按条数组批改成了按 token 预算组批，每批从 16 条变成 **71 条**。
有效 batch 涨了 4 倍多，但 lr 还是按小 batch 给的 `5e-5` —— 等效学习率只有该有的 1/4，
属于严重欠拟合。连训练集原文都复现不出来，就是欠拟合的铁证。

修法：`lr 5e-5 → 2e-4`，`accum 2 → 1`。

### 第 2 轮：loss 0.852，还是停不下来

学习率修完，loss 从 1.595 掉到 0.852，看起来很好。**但回复长度一点没变短。**

这次直接去查 label 构造，找到了真正的元凶：

```python
full = tok.apply_chat_template(msgs, tokenize=False)   # 结尾是 ……<|im_end|>
ids  = tok(full)["input_ids"]
sub  = tok(m["content"])["input_ids"]                  # 只有正文，没有 <|im_end|>
labels[s:e] = ids[s:e]                                 # ← 结束符被标成 -100
```

### Bug 2：`<|im_end|>` 从来没进过 labels

模型学会了「该说什么」，**从没学过「说到哪停」**。所以 loss 再低也没用 —— 它只是不知道
该结束。151645 这个 token 在语料里出现 27,298 次，训练时全被屏蔽了。

修法：assistant 正文之后找紧随的 `<|im_end|>`，把它一起纳入监督。

### 第 3 轮：26/26 全过，但「你好」全答成「刚才不是说过了吗」

修完结束符，长度从 87 字掉到 **13 字**，探针一次全过。但采样测试发现「你好」连续 4 次
全是同一句「刚才不是说过了吗」。

查数据：

```
完全匹配「花海：你好」的样本：10 条
其中 5 条回答是「刚才不是说过了吗」的变体
```

### Bug 3：多轮场景的「重复问候」被塞进了单轮

首轮对话里说「刚才不是说过了吗」逻辑上根本不成立，模型却学成了主导回答。全库扫一遍，
这类污染样本共 **86 条**，正好砸在「你好」「你是谁」「晚安」这些最高频的场景上。

而真正的问候语语料少得离谱：「你好」5 条、「早上好」2 条、「早」2 条。

修法两条：
1. 删掉 86 条污染样本
2. 手写 384 条问候语料（`scripts/../extra_greet.py`），并把 62% 的样本分配给核心高频词本身，
   避免被 8 个变体稀释

补完后覆盖：「你好」40 条、「早上好」37、「在吗」64、「晚安」40、「再见」27、「你是谁」22。

### 第 4 轮：定稿

| 项目 | 值 |
|---|---|
| 数据 | 22,493 train / 686 valid |
| 步数 | 894 步（3 epoch） |
| 耗时 | **44.6 分钟** |

## 四、显存怎么吃准的

按条数组批在这份语料上行不通 —— 长度差 14 倍，bs=16 直接 OOM，bs=12 跑到第 149 步炸，
bs=24 在 384 步炸。**探测 20 步不 OOM 不代表能跑完**，只是没抽到最长那批。

改成按 token 预算贪心装箱，且成本按 **padding 后**的 `批内样本数 × 批内最长` 算（只累加
真实 token 数是错的，短样本 padding 到等长后开销一样）：

| token 预算 | 显存峰值 | 结果 |
|---|---|---|
| 3000 | 21.8 G | 贴近上限 |
| 6000 | — | OOM（CE 要 4.67 G） |
| 5000 | 20.9 G | 能跑 |
| **4500** | **19.4 G** | 采用，留 4.6 G 余量 |

顺带两个坑：8bit 量化和 peft 0.13.2 不兼容；`gradient_checkpointing_kwargs={"use_reentrant": False}`
能省 10–15% 时间。

## 五、验收结果

26 条探针，4 类门槛全 PASS：

```
通过 26/26 = 100%
长度   中位 11 / p90 24 / 最大 27 字
PASS 纯输入人设（自称亚托莉，不带 system）
PASS 无底座泄漏（不吐 Qwen / 通义千问 / 阿里巴巴）
PASS 无客服腔（不出现「很抱歉」「我理解您」）
PASS 长度收住
```

高频词抽样（T=0.8，各采样 5 次）：

| 输入 | 输出 |
|---|---|
| 你好 | 嗨，怎么样？／嗯，有事吗？／嗯？在呢。／你好。今天有事吗？ |
| 早上好 | 早啊（揉了揉眼）／早上好，花海先生。今天也辛苦了。／早。……你起得比我晚。 |
| 晚安 | 嗯……睡吧。／晚安。梦里见。／晚安～（小声） |
| 你是谁 | 亚托莉。／我是亚托莉，YHN-04B-009。 |
| 我好累 | 嗯，想靠会儿就靠会儿吧。 |
| 帮我写个python脚本 | 不会哦，这个得自己学。 |

多轮也接得住：

```
花海：今天上班被组长骂了   → 嗯……（皱眉）怎么回事？
花海：我是不是真的很差劲   → 才不是。你只是今天运气不好而已。
花海：算了 不想说了       → 嗯，那就不说了。（坐在旁边）
```

## 六、已知问题

1. **「算了不说了」会退化成「嗯嗯～～～………………再聊」** —— 波浪号加省略号是语料残留
   模式，下版清。上线后用户实际撞到过。
2. 「在吗」约 1/5 概率答成「喂，不是刚问过嘛」—— 多轮语料仍有残留。
3. A14「夸夸我」质量不稳，会编造不存在的画。
4. X 类（极短应答）总量只有 106 条，占 0.3%，权重偏薄。

## 七、复现

```bash
# 训练
python scripts/train_v7.py \
  --data data/train.jsonl --val data/valid.jsonl \
  --model models/Qwen2.5-7B-Instruct --out outputs/atri-v7-lora \
  --epochs 3 --accum 1 --gc --token-budget 4500 --lr 2e-4

# 推理（注意：不要 system，user 前加「花海：」）
python scripts/chat_v7.py \
  --base models/Qwen2.5-7B-Instruct --adapter outputs/atri-v7-lora \
  --load-4bit on --once "我好累"
```

部署到纯 CPU 走 llama.cpp，见 [`deploy/README.md`](../deploy/README.md)。
